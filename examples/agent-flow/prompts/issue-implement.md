# Objective

Implement the approved plan for the GitHub issue in the current checkout.

Before editing, inspect the current git status and governing guidance for every file you will touch. Preserve unrelated user changes and do not rewrite or discard work outside the issue. Make the smallest coherent change that satisfies the issue and the traceability matrix.

Add or update tests with the implementation. Follow applicable repository and upstream guidance exactly. Run focused checks while working. Do not commit, push, or create a pull request in this step.

If you encounter a material ambiguity, surprising repository state, destructive migration, missing credential, or conflict with the approved plan, send a focused question to the Desktop parent and wait. Include the available options and consequences. Do not guess through a consequential decision.

# Output

Return a Markdown implementation report containing:

- files and behavior changed;
- acceptance criteria satisfied;
- guidance requirements applied;
- tests added or updated and focused commands run;
- deviations from the plan with reasons;
- remaining concerns or questions.
