# Review Workflows

Use the relevant guidance skills before evaluating a change. Keep the supporting review material lazy:

- Load `references/architecture-rubric.md` for structure and architecture reviews.
- Load `references/findings-template.md` when preparing a complete findings report.
- Load `references/delta-matrix-template.md` when comparing a change against the expected pattern.
- Load `references/antipatterns.md` when checking for known discouraged shapes.

Do not treat a reference as a replacement for the applicable global, language, framework, or project guidance skill.
